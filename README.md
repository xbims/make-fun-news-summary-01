# News summary — 11 November 2026

Entry for make.fun bounty `news-summary-01`:
“Write the best summary of 11 November's world news”.

`main.py` (Python 3.13, standard library only) writes one English
summary, 1,423 characters, to `/output/entry.txt`. It uses no network,
no clock and no randomness, so two runs produce identical bytes.

`entry.txt` in this folder is a local preview copy of that output.

Stories whose underlying event was 10 November 2026 were deliberately
left out, even when they were widely reported on 11 November.
